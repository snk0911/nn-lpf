# nn-lpf
A collection of different low pass filters which demonstrates methods to antialias neural network architectures. LPF improve the accuracy and shift robustness of CNNs. This project was done for my bachelor thesis and should support further research in antialiased networks. In addition, adaptive polyphase sampling is implemented as a reference and theoretical ceiling comparison to the implemented low pass filters on this repository.

This repository will be improved in the future. Not all methods, measures and metrics are included.
